Sharing your sheet so the site can read it

  • Google Sheets: Share → General access → "Anyone with the link" (Viewer). Paste the normal link; the site converts it. If your list is on a second tab, open that tab first so the link includes #gid=.
  • Excel on OneDrive/SharePoint: Share → "Anyone with the link can view", then paste. If your company blocks anonymous links, use the upload option above.
  • The sheet needs one column of MC numbers. "MC123456", "MC-123456" and "123456" all match.

Google Sheet & import

Keep loads in sync with a Google Sheet

Keep your loads in a Google Sheet, one row per load. The site checks it every 5 minutes: new row → load posted, edited row → load updated, deleted row → load closed (its bids are kept). Every row needs a Load #. Share the sheet as "Anyone with the link → Viewer". Loads you add here in admin aren't touched.

Download column template
Or import a file once

Upload a .csv or .xlsx with one load per row. Columns are matched by header name (e.g. origin_city, origin_state, dest_city, dest_state, pickup_date, equipment, weight, bid_deadline, target_rate). Rows without an origin and destination are skipped.
